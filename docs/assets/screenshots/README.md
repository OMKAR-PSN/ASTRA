# Screenshots

Place real application captures here before publishing.

Preferred files:
- `mission-overview.png` — Mission Overview tab
- `guided-check-in.png` — Guided Check-In first step
- `body-map.png` — Interactive Body Map
- `assessment.png` — Plain-Language Assessment
- `replay.png` — Mission Health Replay
- `delivery.png` — Reports & Delivery tab

**Guidelines:**
- Use actual application captures only — no mockups or fabricated screens.
- Optimize file size (target < 300 KB each) before committing.
- Do not publish screenshots containing real personal health data.
- Descriptive filenames only (lowercase, hyphen-separated).

See the [Judge Demo Runbook](../JUDGE_DEMO_RUNBOOK.md) for which screens to capture.
